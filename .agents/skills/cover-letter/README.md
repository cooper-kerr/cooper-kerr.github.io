# Cover Letter Skill

Draft Cooper Kerr's cover letters, application emails, recruiter notes, and short role-specific introductions from this repository's career context.

## Quick Start

Use this skill when a job application needs a personable pitch grounded in Cooper's actual experience.

The skill reads `career_context.md` first, then uses structured data under `data/` when checking profile details or site-backed wording.

## Source Files

- `career_context.md`
- `data/profile.json`
- `data/experience.json`
- `data/projects.json`
- `data/skills.json`

## Guardrail

Use company-specific claims only when the user provides them or current research verifies them. Keep Cooper's experience claims tied to the repo or to facts Cooper provides in the current conversation.
